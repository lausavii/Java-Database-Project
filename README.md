This programming projects features the use of Java along with SQLite to create a University Database that holds student information.

This project shows how to create a database, and how we can write a Java application to connect to a database, print out its contents, or modify its information.

Steps Completed:
Add two new rows to the database, and print a message confirming that a new row of data was added.
Print the database, as a 2D ArrayList.
Delete two rows from the databases. Display a message confirming that a row of data was deleted.
Print the database, as a DefaultTableModel.
Execute a query to search for a certain student or group of students 
Print the results of your query to the screen, as a 2D ArrayList.
Update three values within the table.
Print the database, as a DefaultTableModel.
